# TETRIS - Pastel Edition 🌸🎮

ブラウザで軽快に遊べる、ふんわりやさしいパステルカラーの本格Webテトリスです。
PCキーボードとスマートフォンのタッチ操作の両方に完全対応しています。

---

## 🌟 特徴・こだわり機能

1. **本格テトリス仕様（SRS & 7-Bag）**
   - **7-Bag ランダマイザ**: 7種のミノが偏りなく均等に出現する公式ガイドライン準拠仕様
   - **SRS（スーパーローテーションシステム）**: 壁際での回転補正（壁キック）に対応
   - **ゴーストピース**: ミノの落下地点をやさしい半透明パステルでリアルタイム予測表示
   - **ホールド機能**: 現在のミノをストックしてピンチを回避
   - **NEXTキュー**: 次に出てくるミノを最大3手先まで可視化

2. **Web Audio API によるやさしい音響**
   - 外部音声ファイル不要！コード生成によるシンセサイザー効果音（移動、回転、落下、消去、レベルアップ、ゲームオーバー）
   - 名曲「コロブチカ (Korobeiniki)」のオルゴール・トイピアノ風BGM自動演奏（BGM切り替えボタンでON/OFF可能）

3. **ふんわりパステル＆キャンディビジュアル**
   - 丸みのあるブロックとぷっくりした光沢ハイライト
   - すりガラス調のパステルUIと「M PLUS Rounded 1c」「Quicksand」フォント
   - レベルアップによるスピードアップ＆スコア計算システム
   - ローカルストレージ連携によるハイスコア自動保存

4. **マルチデバイス対応**
   - PCキーボード操作対応
   - スマートフォン・タブレット向けのオンスクリーンタッチボタン（長押し移動対応）

## 🕹️ 操作方法

### PCキーボード
| 操作 | キー |
|---|---|
| **左右移動** | <kbd>←</kbd> / <kbd>→</kbd> または <kbd>A</kbd> / <kbd>D</kbd> |
| **右回転** | <kbd>↑</kbd> または <kbd>X</kbd> |
| **左回転** | <kbd>Z</kbd> |
| **ソフトドロップ（高速落下）** | <kbd>↓</kbd> または <kbd>S</kbd> |
| **ハードドロップ（一瞬で設置）** | <kbd>Space</kbd> |
| **ホールド** | <kbd>C</kbd> または <kbd>Shift</kbd> |
| **一時停止（ポーズ）** | <kbd>P</kbd> または <kbd>Esc</kbd> |

### モバイル / タッチ操作
画面下部のコントローラーボタンで直感的に操作できます：
- `◀` `▶` : 左右移動（長押しで連続移動）
- `▼` : ソフトドロップ（長押しで連続落下）
- `⚡ DROP` : ハードドロップ
- `⟲` `⟳` : 左回転 / 右回転
- `HOLD` : ホールド

## 🚀 起動方法

ローカルWebサーバーを起動してブラウザで開きます。

```bash
# Python 3 の場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` にアクセスするとプレイできます。
Codespaces環境では、「Ports」タブからポート `8080` の地球アイコン（Open in Browser）をクリックして開けます。
